## 1. 简介

Ships 是一款常驻 macOS 菜单栏的开发者工具箱。点击托盘图标，会在图标正下方弹出一个 400 × 500 的轻量面板，内置时间戳、IP、网段、进制、编码、JSON 等常用小工具，以及 SSH 主机管理。

**设计原则**

- 点击托盘即用，不占用 Dock、不打断当前工作。
- 顶部图标切换工具，下方为工具主体，底部显示版本与设置入口。
- 输入即实时反馈，无需点击“计算”按钮。
- 支持浅色 / 深色 / 跟随系统，主题色可自定义。
- 界面简洁统一，颜色、圆角、间距由统一设计变量控制。

---

## 2. 安装与启动

**开发运行**

```bash
pnpm install
pnpm start
```

启动后不会出现常规窗口，只会在菜单栏出现 Ships 的托盘图标。

**打包安装（DMG）**

```bash
pnpm dist:mac      # 产出 release/Ships-v<version>-arm64.dmg
```

打开 DMG，将 Ships 拖入“应用程序”即可。应用为菜单栏 Agent（不显示 Dock 图标）。

---

## 3. 托盘与主界面

- **左键托盘图标**：在图标下方居中弹出面板；再次点击或点击别处（失焦）即隐藏。
- **右键托盘图标**：菜单提供“打开设置”“退出 Ships”。
- **Esc 键**：隐藏面板。
- **底部栏**：左侧为版本号，右侧为设置入口（齿轮）。

面板由三部分组成：顶部 TAB 图标区、中部内容区、底部信息栏。

---

## 4. 工具使用

### 4.1 时间戳转换

- 顶部显示**实时当前时间**，并给出对应的秒 / 毫秒 / 纳秒，可一键复制。
- 「时间戳 → 日期」：输入时间戳，自动识别单位（≤11 位按秒、≤15 位按毫秒、其余按纳秒），也可手动选择单位；输出本地时间、UTC、ISO 8601 与相对时间。
- 「日期 → 时间戳」：输入如 `2024-01-01 12:00:00`，输出秒 / 毫秒 / 纳秒。

### 4.2 IP 与数字转换

- 输入 IP（IPv4/IPv6）或数字，自动识别输入类型。
- 输出 IP 地址、十进制、十六进制、二进制。
- 数字超过 `4294967295` 时，IP 行为空并提示超出 IPv4 范围。

### 4.3 网段与掩码计算

- 支持 `192.168.1.10/24`、`192.168.1.0 255.255.255.0` 等写法；未给出掩码时按 `/24` 计算并提示。
- 输出网络地址、广播地址、可用地址范围、可用主机数、子网掩码、反掩码（通配符）、网络前缀、掩码二进制、地址类型（私有 / 公网 / 环回 / 链路本地 / CGNAT）。

### 4.4 进制转换

- 二进制、八进制、十进制、十六进制四行**双向实时同步**：在任意一行输入，其余自动换算。
- 另提供 2–36 的自定义进制。
- 实时显示“位宽”“字节”统计。

### 4.5 字符串编码转换

- 在“字符串 / 十六进制 / ASCII 十进制 / Base64”任意一侧输入，其余实时同步（基于 UTF-8）。
- 输入非法时该字段标红，不影响其他字段。

### 4.6 JSON 格式化

- 粘贴或输入 JSON 即自动格式化并语法高亮。
- 支持缩进（2 空格 / 4 空格 / Tab）、键排序、压缩、清空、复制结果。
- 解析失败时给出错误原因与行列位置。

## 5. SSH 管理

数据来源为 `~/.ssh/config`（忽略 `Host *` 等通配符条目）。

**主机列表**

每行显示：系统图标、`用户名@地址:端口`（端口为 22 时不显示端口）、别名，以及右侧的“连接”“探测操作系统”两个按钮。

**连接**

点击连接按钮，会打开 iTerm 新窗口并执行按配置拼装的 SSH 命令：

```
ssh [-p 端口] [-i 私钥] [-J 跳板机] [用户名@]主机
```

成功或失败会在面板顶部提示。

**探测操作系统**

点击探测按钮后在**后台**通过 SSH 连接执行 `uname -s`（无法识别时回退 Windows `ver`），归类为 macOS / Linux / Windows / BSD / 未知，并更新左侧系统图标；结果会缓存，探测期间按钮显示旋转态。

**增删改（在设置中）**

见下一节「SSH 管理」。

## 6. 设置

设置以**普通窗口**打开，采用左右分栏：左侧为分类导航，右侧为具体设置。

### 6.1 Ships 设置

| 设置项 | 说明 |
| --- | --- |
| 语言 | 简体中文 / English |
| 外观 | 跟随系统 / 浅色 / 深色 |
| 主题色 | 预置色板 + 自定义取色 |
| 开机自启 | 登录时自动启动 Ships |
| 数据文件夹 | 一键打开应用数据目录 |
| 关于 | 显示当前版本 |

### 6.2 SSH 管理

- 以列表展示 `~/.ssh/config` 中的主机，支持**新增、编辑、删除**（删除有二次确认）。
- 可维护字段：别名（必填）、HostName、User、Port、IdentityFile、ProxyJump。
- 保存时**保留原文件中未被管理的指令与注释**；新增主机追加到文件末尾。

## 7. 数据与位置

| 内容 | 位置 |
| --- | --- |
| 应用设置 | `~/Library/Application Support/ships/settings.json` |
| SSH 探测缓存 | `~/Library/Application Support/ships/ssh-detected.json` |
| SSH 配置（用户维护） | `~/.ssh/config` |

应用不保存密码、令牌等机密信息；SSH 私钥由用户自行管理，不会复制到应用数据目录。

## 8. 常见问题

**面板没有出现？**
确认菜单栏有 Ships 图标；点击图标即可展开。应用不显示 Dock 图标属正常现象。

**SSH 列表为空？**
确认 `~/.ssh/config` 存在且包含具体主机（`Host *` 等通配符条目不会显示）。

**探测操作系统失败？**
探测依赖本机 SSH 免密或代理（`SSH_AUTH_SOCK`）以及主机可达；超时为 8 秒，失败会标记为“未知”。

**如何更换主题色 / 语言？**
打开设置 → Ships 设置，修改后主面板实时生效。
