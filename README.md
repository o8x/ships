# Vessel

<img src="assets/imgs/app.png" alt="Vessel" width="120" />

**English** | [简体中文](README.zh-CN.md)

Vessel is a lightweight macOS menu bar toolbox for developers. It stays in the tray and drops a small panel right below the icon, so everyday utilities are one click away.

## Tools

- **SSH Manager** — browse `~/.ssh/config`, grouped into accordions; connect in one click, edit hosts, and store passwords securely.
- **2FA Codes** — generate TOTP codes from `otpauth://` links or Base32 secrets, with countdown and one-click copy.
- **Timestamp** — convert seconds / milliseconds / nanoseconds to and from dates, with offsets and time-difference calculations.
- **IP / Subnet** — parse IP, CIDR and netmask values; show network range, usable hosts, host count and geolocation.
- **Encode** — live string / Base64 / hex / URL / ASCII conversion, plus QR Code and Data Matrix generation.
- **Radix** — convert between binary, octal, decimal, hex and custom bases from 2 to 36.
- **JSON** — format, highlight, sort keys, minify and inspect as a collapsible tree.
- **Hash** — MD5 / SHA1 / SHA256 for text or large local files.
- **Nutrition** — per-100g nutrition, salt / kcal / kJ conversion, TDEE calculator and saved products.
- **Clipboard** — recent text, image and SVG clipboard history with one-click copy or clear.
- **Games** — FC / GBC / GBA / N64 / SFC library with covers, fuzzy search, collapsible categories, saves and FDS BIOS support.

## More

- **Floating terminal** — an always-on-top terminal window that can run SSH directly.
- **File manager** — a standalone SFTP window with upload, download and open-in-VS-Code actions.
- **Network test** — run TCP / UDP / HTTP / ICMP / ARP checks and subnet scans in a real terminal.
- **Settings** — themes and Liquid Glass, hotkeys, SSH credentials, updates, config import / export and data cleanup.

Built with Electron and Tailwind CSS. No Dock icon, no "calculate" button — everything updates as you type.
