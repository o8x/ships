# Ships

<img src="assets/imgs/app.png" alt="Ships" width="120" />

**English** | [简体中文](README.zh-CN.md)

Ships is a lightweight macOS menu bar toolbox for developers. It stays in the tray and drops a small panel right below the icon, so everyday utilities are one click away: timestamps, IP / subnet math, base and encoding conversion, JSON, hashing and clipboard history, plus SSH host management, a directory browser and a floating terminal.

Built with Electron and Tailwind CSS. No Dock icon, no "calculate" button — everything updates as you type.
