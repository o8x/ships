# Vessel

<img src="assets/imgs/app.png" alt="Vessel" width="120" />

[English](README.md) | **简体中文**

Vessel 是一款面向开发者的 macOS 菜单栏工具箱：常驻托盘，点击即在托盘图标下方展开一个轻量面板，常用小工具触手可及。

## 工具

- **SSH 管理**：读取 `~/.ssh/config`，按分组展示；一键连接、编辑主机，并加密保存密码。
- **2FA 验证码**：从 `otpauth://` 链接或 Base32 密钥生成 TOTP 验证码，带倒计时与一键复制。
- **时间戳转换**：秒 / 毫秒 / 纳秒与日期互转，支持偏移与时间差计算。
- **IP / 网段与掩码**：解析 IP、CIDR、子网掩码，显示网络地址、可用范围、主机数与归属地。
- **编码转换**：字符串 / Base64 / 十六进制 / URL / ASCII 实时互转，并生成二维码与 Data Matrix。
- **进制转换**：2 / 8 / 10 / 16 及 2–36 自定义进制双向转换。
- **JSON 格式化**：格式化、高亮、排序、压缩与结构树查看。
- **哈希计算**：MD5 / SHA1 / SHA256，支持文本与本地大文件。
- **营养成分**：按每 100g 计算营养、盐 / 千卡 / 千焦，内置 TDEE 计算与商品记录。
- **剪贴板**：保留最近文本 / 图片 / SVG 记录，一键复制或清空。
- **游戏**：FC / GBA / N64 / SFC 游戏库，支持封面、模糊搜索、手风琴分类、存档与 FDS BIOS。

## 更多

- **悬浮终端**：置顶终端窗口，可直接执行 SSH。
- **文件管理**：独立 SFTP 文件窗口，支持上传 / 下载与用 VS Code 打开。
- **网络测试**：在内置终端中执行 TCP / UDP / HTTP / ICMP / ARP 测试与网段扫描。
- **设置**：主题 / Liquid Glass、快捷键、SSH 凭据、检查更新、配置导入导出与数据清理。

基于 Electron + Tailwind CSS 实现，不占用 Dock，输入即时反馈、无需点「计算」。
